# Vidyst landing page

Next.js 15 · React 19 · Tailwind CSS v4 · Motion

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- `app/page.tsx` – page sections
- `components/Bento.tsx` – the six animated feature cards
- `components/Studio.tsx` – hero app mockup
- `components/ThemeToggle.tsx` – dark/light toggle (saved as `vidyst-theme` in localStorage)
- `app/globals.css` – theme tokens and looping animations
- `public/logo.png` – logo
